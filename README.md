# Серввер TFC Minecraft

## Быстрые ссылки

* Веб карта мира - [BlueMap](http://91.240.87.20:8100/#1mb1r:976:0:2480:1500:0:0:0:1:flat).

## Подключение к серверу
1. Зарегистрироваться [здесь](http://91.240.87.20:3000).
2. В клиенте minecraft: Сетевая игра -> Добавить -> 91.240.87.20 -> Подключиться

## Установка клиента
Сервер запущен на версии Minecraft v1.21.1

Зависимости:
* NeoForge v21.1.218
* TerraFirmaCraft v4.0.18-beta
* Patchouli v1.21.1-92-NEOFORGE
* JEI v19.27.0.340

Моды и протестированный шейдер можно найти в релизах в этом репозитории.

Можно собрать свой билд руками, но рекомендуется через T-Launcher.
